# BuildWise Home Wireframe

## 1. Header

왼쪽:

- BuildWise

Navigation:

- Home
- How it works
- Compare
- Evidence

현재 Prototype v1에서는 별도 Evidence 페이지를 만들지 않는다.
Evidence는 Home 화면의 5장 Evidence Preview 영역으로 이동하는
섹션 앵커 역할을 한다.

오른쪽 CTA:

- 조건 비교 시작

## 2. Hero

메인 카피:

> AI 활용의 차이는
> '얼마나 많이 쓰느냐'가 아니라
> '우리에게 무엇이 필요한지 정확히 아느냐'에서 시작됩니다.

서브 카피:

> 업무마다 흩어진 선택을 기준으로 만들고,
> 그 기준을 쌓아 전사적인 AI 활용 체계로 확장합니다.
>
> BuildWise는 그 판단을 돕습니다.

Primary CTA:

- 우리 조건으로 비교하기

범위 안내:

- PDF 문서 검토 업무부터 검증 중인 BuildWise Prototype v1

## 3. Why BuildWise

제목:

> AI를 찾는 것보다 어려운 건
> 우리 업무에 어디까지 활용할지 판단하는 일입니다.

세 가지 질문:

1. 01 기존 솔루션으로 가능한가
2. 02 우리 조건에 맞는 후보는 무엇인가
3. 03 무엇을 더 확인해야 하는가

## 4. How it works Preview

4단계:

1. 01 업무 조건 정의
2. 02 기존 AI 시장과 비교
3. 03 Gap과 판단 근거 확인
4. 04 Decision Report 확인

CTA:

- 사용 방법 보기

## 5. Evidence Preview

현재 PoC에서 실제 확인된 숫자만 사용한다.

- 원본 솔루션 27개
- 비교 가능한 정제 데이터 14개
- $0 이상 $10 미만 후보 8개

근거 구조:

- 원문 URL
- 수집 시점
- 가격 원문
- 기능 확인 상태

중요:

이 숫자가 전체 PDF AI 시장을 대표한다고 표현하지 않는다.
현재 수집한 표본 기준이라고 표시한다.

CTA:

- 근거 구조 보기

이 CTA는 별도 페이지로 이동하지 않고,
Evidence Preview 영역 안의 근거 구조 설명 영역으로 연결한다.

향후 별도 Evidence 페이지는 확장 가능성으로만 남긴다.

## 6. Final CTA

카피:

> AI를 더 많이 도입하기 전에,
> 우리 업무에 필요한 범위부터 확인하세요.

CTA:

- 조건 비교 시작

## 7. Layout 원칙

- Desktop 우선
- White 중심
- Deep Navy 중심 정보 위계
- Blue CTA
- 넓은 여백
- 직선적 Grid
- 과도한 카드 남발 금지
- 장식보다 정보 구조 우선
- 제품 로고 나열 금지
- HIMEC 사이트를 복제하지 않고 엔지니어링 B2B 분위기만 참고

## 8. 화면에서 사용자가 느껴야 하는 것

| 시점 | 사용자가 느껴야 하는 것 |
| --- | --- |

| 첫 15초 | "내 조건을 넣으면 활용 가능한 범위와 확인할 항목을 알 수 있겠구나." |
| CTA를 누르기 전 | "결과에 근거가 있고, 회의나 검토에 가져갈 수 있겠구나." |
